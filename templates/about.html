About This Project

The Student Academic Management System is a database-driven web application developed using Python, Flask, and SQLite for managing student academic records.

The application provides an easy-to-use interface for storing, searching, updating, and managing student information.

Features

  • Add Student Records
  • View Student Records
  • Edit Student Information
  • Delete Student Information
  • Search Students
  • Dashboard Statistics
  • Academic Information Management

Technologies Used

Python • Flask • SQLite • HTML • CSS • JavaScript
